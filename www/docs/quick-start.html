01 / Start

Quick start

Start with one teammate and one task. Open your workspace, connect a model provider, and review the result in the conversation.

Web workspace Free Muster app Bring your own API key

1. Open Muster

Open Muster in your browser, sign in using an available option, and complete the setup steps shown for your account. No server deployment is needed. The account and device guide explains connections, data storage and existing desktop installations.

Desktop downloads and companion availability are listed under Install & apps. You can begin in the browser before configuring device tools.

2. Connect a model provider

Bring a supported provider API key through setup or Settings → Providers. Muster is a free app; you pay your provider for model usage. A Muster sign-in and a provider subscription are separate, and a chat subscription does not necessarily include API access.

Choose an engine and model available to your workspace. Existing desktop installations can also use supported agent CLIs or local models on that computer. A local model on your laptop is not automatically reachable from the hosted web service. See Engines & models.

3. Create your first bot

Create a bot from the roster. Give it a name, a role and a short brief: what you want it to handle, how it should report back, and what it must ask before changing. Select the engine and model you connected.

4. Send a small first task

Try: “Help me plan tomorrow. Ask what you need to know, then draft a short plan here.” Review its reply before adding tools or scheduling repeated work.

When a supported engine requests permission, Muster shows an approval card. Read the proposed action and destination, then allow or deny it. Task receipts record available duration, usage and cost information; reporting depends on the engine.

5. Add connections as your work needs them

Use Settings → Connections for the services your workspace supports. Complete each service's authorization separately. Device work requires an available computer and the relevant permissions; see Account & device setup.

Follow any Drive step shown in setup and review its consent screen. Verify backup and restore results before relying on them. Google sign-in alone does not establish Drive access, automatic sync or recovery of every credential.
