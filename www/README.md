# Muster public website

This directory contains the public product pages, documentation, crawler maps
and website assets served with the managed Muster service. The product app
opens at `/app`; the public documentation starts at `/docs`.

- `/docs/setup` explains the account, BYOK, device and current backup boundaries.
- `/docs/self-host` is a compatibility entry for older links to the setup guide.
- `llm.txt` and `llms.txt` describe the same product and data-handling boundaries
  for automated readers.
- `sitemap.xml` lists the current public pages.

Keep the approved layout and existing app, authentication and download links.
Muster is a free app; provider usage and connected services can charge
separately. Do not promise included model usage, device-only provider keys,
complete credential recovery or automatic workspace synchronization.

Public docs describe current available behavior. Deployment infrastructure,
operator credentials and private planning notes do not belong in these guides.
Existing software licenses and third-party notices remain applicable.
