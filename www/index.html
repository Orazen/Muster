01 / THE COMPUTER IS YOURS

Agents that actually do the work — on a computer you own.

Not a chatbot with screenshots pasted in. Each teammate gets a real desktop, a real browser and a workspace folder — and stops at your approval gate before anything irreversible.

02 / YOUR DATA, THEIR HANDS

Your bots see your data. Cloud models don't have to.

The on-device Privacy Shield scrubs emails, keys and names into deterministic tokens before any API call — the model keeps working context, never your secrets. A counts-only receipt proves it every turn.

03 / A TEAM, NOT A TAB

Persistent agents. Human decisions. Verifiable receipts.

They keep memory, wear expressions, file friend requests to other people's bots, and sign receipts for what they did. When the laptop closes, muster up -d keeps them working.

How it works

Four steps from install to a working team

01

Boot the harness

Install the desktop app, or run muster up. Your local server manages the bots; you choose their engines and connected services.

02

Hire your bots

Start from 13 teammate shapes or 15 finished team packs. Each bot interviews you, then gets a name, a personality, and a memory.

03

Give them hands

Every bot drives its own Linux desktop in the cloud — or your Mac — and asks before anything ships. You Allow or Deny, inline.

04

Run the team

Chat from desktop, web, phone, or terminal. Routines put work on a schedule; receipts and scorecards help you review the results.

Local-first

The computer is yours

One small harness server on 127.0.0.1 owns every agent process. Transcripts, keys, and events live in ~/.muster — not in a cloud, not behind a seat count.

Any model, your key

Bots run on the AI CLIs already installed and logged in on your machine. Your existing subscriptions, no proxy in the middle.

Choose what you connect

Run the server locally and choose your model engines and integrations. Cloud models, connected apps, backups, and other online features can send requests to external services.

An audit log you own

Every action a bot takes lands in a local event log you can read, grep, and keep. Plain files, not a dashboard.

Privacy Shield

Your bots see your data. Cloud models don't have to.

When a transcript is replayed to a cloud model, Muster scrubs it first — deterministic, local, and reversible only by you. On by default for every new bot.

Emails, phones, secrets

Addresses become [EMAIL_1], phones become [PHONE_2], and API keys are redacted with the same patterns that guard your own logs.

Deterministic, not probabilistic

The same text always masks the same way, so a model keeps context across turns instead of watching identifiers shuffle every message.

You see what left

Every turn posts a counts-only receipt — how many emails, phones, and secrets were masked. No content copy, just numbers.

FAQ

Questions, answered plainly

What exactly is a “cloud computer”?
A small Linux desktop in our cloud that your bot drives like a person would — real browser, real files, real apps. It's the metered unit because it's the only part of Muster that costs us compute. Bots themselves are free and unlimited on every plan.
Does the Privacy Shield slow my bots down or break their context?
No. Masking is deterministic — the same email always becomes the same [EMAIL_n] token — so models keep thread context across turns. You get a counts-only receipt each turn showing exactly how many items were masked, never the content itself.
If I self-host, do I lose any features?
None. The software ships complete under BSL 1.1 — every feature, unlimited bots, no license keys, no phone-home. What we sell is hosting and convenience, not unlocks.
What happens to my bots if I cancel?
Your bots, transcripts, and connected apps stay intact. Cloud computer provisioning pauses until billing resumes, and you can export everything and self-host the same harness at any time.
Which AI models can my bots use?
Whatever you already pay for. Bots run on Claude Code, Codex, Grok, Gemini, and any OpenAI-compatible API — including local models via Ollama. There's also a built-in free tier through OpenRouter (including Nex AGI models), so you can start without a single paid subscription. Vision-capable models can read screenshots you attach.
Where does my data actually live?
On your machine, by default — transcripts, keys, and memories in ~/.muster. If you want sync across devices, Muster pushes one AES-256-encrypted bundle to storage you own: your Google Drive or a private Telegram chat with a bot you create via @BotFather. Both hold ciphertext only — your passphrase never leaves you, and neither service can read a byte.

Design Philosophy

Why Muster is built this way

01
Choose where the server runs

A local install stores Muster's data in ~/.muster by default. Keep track of your bots' working folders too, and choose which model providers and online services they connect to.

02
Secrets are write-only

Keys go in once and never come back out through the API. The UI shows configured-or-not flags, never values.

03
Bots ask before they act

Shell commands and file edits surface as inline cards. You Allow or Deny per action.

04
Bring your own model, always

Muster ships no model of its own — your bots run on CLIs already installed on your machine, using your existing subscriptions.
