BEFORE YOU SAY HELLO

A few good
questions.

What should I give my first teammate?+

Start with a small job and enough context to do it: a page of notes, a question with sources, or a list of priorities. Ask for a draft or plan you can review, then continue in the same conversation.

Is the example above a live AI run?+

It is a scripted, interactive preview using fictional sample data. Your choices change the preview, but it does not contact an AI provider, connect an account, or send anything.

Can Muster act in my other tools?+

With supported tools connected and the right permissions, teammates can help beyond the conversation. Available actions and approval behavior depend on the tool, engine, and setup. Review the approval guide before enabling actions.

Where can I use Muster?+

Start in the web workspace or explore the desktop app. The hosted web workspace and a local desktop workspace are distinct; signing in does not automatically merge them. Phone and Watch companion work is in beta. See current downloads for availability. For terminal workflows, explore the CLI setup.

Do I need an AI subscription or API key?+

You need a supported provider connection for AI work. Depending on the engine, that may use a provider login, subscription, API key, or a configured local model. Muster’s app is free; provider usage and other service costs are separate.
