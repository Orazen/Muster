# botdirectory.ai submission runbook

These three templates are ready to submit to https://botdirectory.ai via PR
(its contribution flow is a markdown file per bot — same shape as these).

1. Fork `elie222/botdirectory.ai` (or the account you submit under).
2. Copy each template's **System prompt** block into a new markdown file
   following that repo's existing entry format (front matter + body).
3. One PR per bot keeps review fast; mention "tested in Muster" in the PR body.
4. Each merged PR is a backlink + distribution surface for Muster at zero cost.

Local-first testing: paste any template's system prompt into a new Muster bot
(Settings → New bot → paste into the personality field) and send a real task.
